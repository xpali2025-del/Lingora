# Keyword-tool exports

Store Keyword Planner or other approved keyword-tool CSV exports here. Preserve the source tool, date range, language, and location targeting in a note. If you import volume or difficulty into a content record, keep the original exported value and label its provider. Keyword Planner advertiser competition is not organic SEO difficulty; Google Trends provides relative interest, not an absolute volume.

Do not store API keys, Google credentials, customer data, or private account identifiers here.
