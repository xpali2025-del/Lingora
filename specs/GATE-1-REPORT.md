# تقرير بوابة GATE-1 — تأسيس Lingora

**الحالة: P1 مكتملة؛ أتوقف هنا بانتظار اعتماد GATE-1.** لم أبدأ مرحلة P2 (محرك المحتوى وSEO).

## ما أُنجز

- مشروع Next.js App Router + TypeScript بتصدير ثابت و`trailingSlash`.
- تخطيطان مستقلان: العربية RTL على `/` والإنجليزية LTR على `/en/`.
- رموز ألوان منفصلة لكل مسار، خصائص CSS منطقية، وخطا Inter وIBM Plex Sans Arabic مستضافان محليًا.
- مكتبة مكونات تأسيسية، روابط تبديل لغة تعمل دون JavaScript، وواجهة Decap CMS أولية.
- رؤوس Cloudflare الأمنية، سير CI في GitHub Actions، إعداد نشر يدوي إلى Cloudflare Pages، واختبارات للتتبّع والأنماط والتصدير.
- صفحات المعاينة موسومة `noindex,nofollow`، ومحتواها المؤقت ليس نصًا نهائيًا.

## المخاطر والقيود المفتوحة

- لم يُشغّل GitHub Actions على مستودع بعيد بعد؛ الموجود إعداد محلي للـ workflow.
- إعداد Decap CMS يحوي `OWNER/lingora` ونقطة OAuth تجريبية؛ يلزم ضبطهما وحماية الفرع قبل تفعيله.
- مستندا Architecture Plan وKeywords Workbook غير متاحين، لذا لا تزال بعض المواصفات مشتقة من البرومبت فقط.
- القرار OD-01 مؤجل؛ **لا إطلاق للتجارة** قبل التحقق من حق إعادة البيع وشروط الروابط.
- لا توجد قاعدة بيانات أو APIs أو وحدات عملاء/فواتير/تقارير؛ نطاق P1 المعتمد هو أساس الموقع الثابت، وليس نظام CRM أو محاسبة.

تم تحديث `specs/TRACEABILITY.md`: أدلة REQ-FND-001 إلى REQ-FND-008 تشير إلى تقرير P1، ومتطلبات محرك المحتوى SEO ما تزال بانتظار P2.
